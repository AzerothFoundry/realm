# 发布与贡献

源码独立维护，realm 固定已验证的组件提交、镜像 digest 和插件包 SHA256。修改插件只需在 addons 发布，整体验证后更新 realm 版本清单；不要求更新多层 submodule。后续自动更新通过 PR 完成，不直接改正式版本。

各仓库遵循 GitHub Flow 和 Conventional Commits。上游 fork 保留上游祖先，定制功能通过功能分支审查。新导入版本从相应上游祖先提取净源码差异，排除内部运维回执与用户数据；源工作树与旧历史在本地保留。

通用崩溃、协议或标准 Lua API 兼容修复分别提交小 PR，先确认最新上游尚未修复。自定义 GM 和 Bot 玩法默认维护在 fork，不将全部定制改动打包提交上游。vMaNGOS 自定义行为应放在默认关闭的开关后；benilla 修复需遵循其原版行为证据要求。

二进制分发保留各组件许可证、依赖声明并提供对应准确源码。第三方插件未确认许可前不纳入再分发 ZIP；AutoQuest 当前上游未提供明确 LICENSE，仅记录其 GitHub 来源与修改，发行前确认授权。

镜像按 linux/amd64 与 linux/arm64 独立验证；构建通过不等于运行通过。不要把 ARM64 Mac 运行 Linux 容器称为原生 macOS 服务端已验证。
